# Changelog

## 0.2.0 — 2026-09-22

- Rename the collection to **Float Themes for Positron** and the repository to `positron-float-themes`.
- Add light and Night versions of **Ash**, **Blossom**, **Cappucino**, **Midnight Plum**, and **Sunset Citrus**, bringing the collection to 12 themes.
- Carry over the complete Spring workbench, TextMate, and semantic-token coverage; retain both original Spring themes unchanged.
- Adjust text contrast for the new palettes, including buttons in their hover state. Keep success/error colours distinct from decorative accents.
- Add illustrated README previews with hex values printed on their exact Float palette colours.
- Keep the existing extension ID so installing this VSIX upgrades version 0.1.0.

## 0.1.0 — 2026-08-30

- Add the bright **Float Spring** theme.
- Add the dark **Float Spring Night** theme.
- Theme Positron-specific Console, Variables, Data Explorer, Plots, Packages, notebook, dialog, and memory-usage surfaces.
